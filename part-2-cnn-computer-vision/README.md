## Task 6: CNN Concepts Explained

- **Convolution**: Uses filters to detect edges, textures, and patterns in images.
- **Pooling**: Reduces image size while keeping important features (makes model efficient).
- **ReLU**: Activation function that introduces non-linearity.
- **Why CNN?**: Much better than traditional neural networks for images due to parameter sharing and spatial awareness.
